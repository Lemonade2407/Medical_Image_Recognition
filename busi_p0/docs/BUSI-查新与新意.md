**关键查新发现**：**主流 BUSI 分割工作直接丢弃 133 张正常图**——PH-Net★(CVPR2024)、UGB-SegNet、YOLO 分割基准等**均仅用 647 张病灶图**；本仓库协议**保留全部 780 张**并显式度量"正常图假阳性"。这是 D1–D4 那类"刷 Dice"工作**在协议上根本无法报告**的维度。

**结论**：

- **D1–D5、D8 全部排除**（BUSI 已被占满 / 通用机制已发表 / 与自家结论冲突）。
- **D6（物理先验）留作备选**：仅当愿意补做超声物理建模、且接受"可能不显著"（本身可作 negative result）。
- **D7 排除（且已实证）**：它攻的是"正常图假阳性"这条轴的**特异度**——**基线**上该轴几乎没有空间（监督式正常图前景占比仅 **0.001–0.015**）；**兜底后**虽有空间（0.10–0.26），但门控机制已被 **BTEC-Net + RFS-UNet** 占用（见 三·补）。更关键的是**弃权门单调抑制、只能减前景，不可能提升召回**，会把"部分命中"的病灶图直接变成"完全漏诊"。

> **架构方向整体结论**：BUSI 上"换新骨干/新模块"已无新意空间。本仓库真正可主张的方向**不在架构**，而在**归因与判据**（见第四节贡献 5）。

### 三·补　图像级「有/无病灶」分类器门控（P3 待做项 ⑦，2026-10 查新）

> 命题：把"是否出兜底提示"改由**图像级二分类器**（有/无病灶）决定，而非分割掩膜的 pmax，以消掉 P3 兜底的正常图假阳代价。

| 先例 | 做法 | 与本项关系 |
|---|---|---|
| **BTEC-Net + RFS-UNet**（Cho 等；AUDT 2026 综述 [33]） | 先分类 **normal / abnormal**，**只对 abnormal 图分割**；原文明确"可降低假阳、提升分割精度" | **完全同构**，动机一致 |
| **Two-stage U-Net + SVM**（Front. Bioeng. Biotechnol. 2026） | 分割掩膜全空 → 判为 normal，否则进入第二阶段 | 与当前"空掩膜门控"同构 |
| **WO2026139056A1**（专利） | 分割无病灶 → 不再检测；用二分类决定是否需要检测 | 专利层面先例 |
| **Rad-VLSM**（arXiv:2605.18130） | BLIP-2 定位 → 候选框 → SAM 多候选聚合 + 诊断 | 与 P3 自动提示管线最接近 |
| **Prompt-Free SAM 多任务**（arXiv:2601.05498） | 3 类（benign/malignant/**normal**）+ 无提示 SAM | 同类多任务框架 |
| **选择性预测 / 弃权**（arXiv:2402.10665、2604.13262） | 图像级"不确定即拒绝输出" | 方法学上游，已成熟 |

**判定**：机制**已被占**，不能作新意。唯一窄缝是"分类器只作**无框兜底**的触发器"（而非全图预筛），并报告"盲区召回 vs 正常图假阳"的权衡；未检索到完全相同的组合，但属同一机制的应用变体，**不足以支撑新意**。

**与 D7 的关系**：D7 否定的是"用弃权门抑制**基线**的正常图假阳"（基线 `fg_ratio` 0.001–0.015，无空间）；本项否定的是"用分类器门控抑制**兜底后**的假阳"（0.10–0.26）——后者有空间，但机制不新。

**定位**：工程补强 / 代价修复，**不作新意主张**。**前置实验判据**：ResNet18 / EfficientNet-B0，128 灰度，3 种子，同冻结划分；测试集三组 P(abnormal)——20 正常 / 9 全盲病灶 / 其余 87 病灶。**9 张全盲命中 ≥7 且正常图误报 ≤2 → 接入；否则放弃**。接入后 Dice 应保持 ~0.640，正常图 `fg_ratio` 由 0.26 降到 <0.02。

**风险**：分类器与分割头面对同一批低对比图，错误可能同样集中在 9 张全盲上；文献中"normal 类 100% 准确"多在易分正常图上，不可外推。


## 四、本文可主张的新意

**贡献 1（方法学）· 统一协议下的跨范式公平基准**
冻结划分 + 同口径指标 + 多种子 mean±std + 配对 Wilcoxon，把 7 种方法钉在同一测试集上。据此**否定了注意力门控**（Δ=−0.0189（3 种子均值差；逐图配对 −0.0271），p=0.5569）——同类工作普遍缺多种子与显著性检验，单次训练的波动（±0.04）足以淹没结论。

**贡献 2 · 推理侧增强的跨范式适用边界 + 适用性判据**
同一套零成本推理增强（后处理/TTA/验证集阈值）在**监督式**上稳定增益（Dice 增益 ≤0.020，boundary 模型 HD95 降 ~38），在**提示式大模型**上**无效甚至有害**（SAM −0.02、MedSAM 崩溃）。给出机理（预测稀疏度/空掩膜比例/形态复杂度）与**是否启用的判据**，可做成"即插即用模块 + 准则"的完整故事。

**贡献 3 · 损失函数的有效边界（经 P1 充分训练校正）**
- **24ep 原结论**：Tversky 的收益依赖模型容量（U-Net **+0.036** vs UNet++ **−0.023**）；**Boundary 单独使用一致有害**。
- **P1 校正（150 epoch + 验证集早停 + 最优轮回滚，3 种子）**：对轻量模型 **训练预算才是主导因素** —— 10 个配置中 9 个提升（**+0.016 ~ +0.074**），最优轮落在 **23–81**（而非 24），即原基线**严重欠拟合**。充分训练后：**Tversky 对轻量模型全面 ≥ CE+Dice**（UNet++ 由 −0.023 **反转为 +0.004**，U-Net +0.009、AttU-Net +0.002），而 **Boundary 仍一致劣于 ce_dice**（U-Net −0.067、AttU-Net −0.062）。**例外：TransUNet + Tversky（−0.023）** —— 重跑后最优轮仅 19–30、早早饱和后持续退化，故 Tversky 的有效边界是**模型依赖**。
- **修正后的主张**：小数据超声分割上 **"训练预算 ≫ 损失选择"（轻量模型）** —— 损失函数之间差距 ≤0.01，远小于训练充分化的 0.02–0.07；并据此说明**损失消融必须在充分训练下进行**，否则结论会被欠拟合掩盖（我们自身即是反例）。Boundary 有害是其中唯一稳健的损失层结论；Tversky 的收益随模型容量反向（重模型甚至有害）。
- 数据：`docs/七种模型对比.md` §7.3 与 `results/p1_summary.md`。

**贡献 4 · 重叠指标与边界指标的解耦**
A 组对 Dice 的增益有限（+0.015）但对 HD95 显著（−24）。说明只报 Dice 会**系统性低估**推理侧增强；建议分割评测同时报告距离类指标。

**贡献 5（新主贡献）· 全自动管线的天花板归因：漏检即瓶颈**
同一协议下，监督式的**漏检**（低对比病灶占 ~79% FN 像素）直接决定全自动提示管线的天花板：粗模型在 **8–11%** 的图上不出框 → 该图整条管线失败 → 端到端从有框子集的 **0.70** 降到 **0.62–0.65**。据此给出**提示传导律**（MedSAM 偏大安全、偏小危险；定位误差 > 尺度误差）与**改进优先级**。数据见 `docs/BUSI-算法优化方案.md` 第二节。

> **边界（重要）**：贡献 5 是**归因/发现**，**不是新方法**。把它落地的"分档提示策略"（`BUSI-算法优化方案.md` 4.1）其部件**均已被发表**——多框提示 + 不确定性 FN/FP 控制 = **FNPC-SAM**；不确定性引导多提示自适应 = **MedSAM-U**；按复杂度自适应选提示 = **MAUP**；目标判定→多提示 = **CamoSAM2**；"检测器召回=精度天花板" = **Tiny-YOLOSAM**。故该策略**仅作工程增益，不作新意主张**。同理，"图像级分类器门控兜底"（4.1⑦）机制已被 **BTEC-Net + RFS-UNet** 占用（见 三·补），只作代价修复。

### 四·补　P3 新意复核（2026-10，基于 v4 实测：150ep × 3 种子）

> 把 P3 的主张逐条对 **v4 数据（150ep × 3 种子，`archive/P3_v4_2026-10-18/`）**。v3（24ep 单种子）已作废，保留在 `archive/P3_v3_2026-10-18/`。

|---|---|---|
| ① 误差可分四类 | 正确 66.7 / 偏移 19.7 / 尺度错 7.7 / 欠自信 2.7 / 全盲 19.3（病灶 8.0 + 正常 11.3） | ✅ 描述成立 |

**升格条件复核**（v3 时列为待测）：① 150ep + 3 种子下"定向 > 通用"达 p<0.05 → **未达（p=0.069）**；② 正常图不劣化 → **未达**。⇒ 仍不升格。
**v3 遗留的前提风险已排除**：担心"150ep 下无框率下降会导致收益缩水"——实测全盲病灶 9→8 张、无框率 11.5%→9.0%，而增益 0.0233→**0.0226**，**几乎未缩水**；且 3/3 种子为正，说明收益来自机制而非欠拟合权重。

## 五、建议的论文主线

> **问题**：BUSI 上方法众多但划分/口径不一，结论不可比，且普遍缺统计检验。
> **方法**：建立统一评估协议 + 统计判定门槛；系统评测"重训侧损失（Tversky/Boundary）"与"推理侧增强（后处理/TTA/阈值）"两条正交轴，并对**漏检 → 自动提示**的传导链做归因。
> **发现**：① 推理增强存在**跨范式适用边界**（监督式有效、提示式有害）；② **训练预算 ≫ 损失选择（轻量模型）** —— 充分训练（150ep）后 Tversky 在轻量模型全面 ≥ CE+Dice、Boundary 仍偏差（原"容量依赖的有效边界"系**欠拟合假象**），但重模型 **TransUNet 上 Tversky 反降（−0.023）** → 边界是**模型依赖**（贡献 3 已校正）；③ 注意力门控不显著；④ Dice 与 HD95 解耦；⑤ **全自动提示的天花板由粗模型漏检决定**（8–11% 无框硬失败，端到端拉低 ~0.05）。
> **对照**：与 KD SAM / FA-SAM / VESSA 等已有工作明确区分（见 一/二），不重复其主张；自动提示只做"瓶颈归因 + 分档提示决策"，不做管线（见 四·贡献 5），也不做分类器门控兜底（= BTEC-Net / RFS-UNet，见 三·补）。
