**关键查新发现**：**主流 BUSI 分割工作直接丢弃 133 张正常图**——PH-Net★(CVPR2024)、UGB-SegNet、YOLO 分割基准等**均仅用 647 张病灶图**；本仓库协议**保留全部 780 张**并显式度量"正常图假阳性"。这是 D1–D4 那类"刷 Dice"工作**在协议上根本无法报告**的维度。

**结论**：

- **D1–D5、D8 全部排除**（BUSI 已被占满 / 通用机制已发表 / 与自家结论冲突）。
- **D6（物理先验）留作备选**：仅当愿意补做超声物理建模、且接受"可能不显著"（本身可作 negative result）。
- **D7 排除（且已实证）**：它攻的是"正常图假阳性"这条轴的**特异度**——**基线**上该轴几乎没有空间（监督式正常图前景占比仅 **0.001–0.015**）；**兜底后**虽有空间（0.10–0.26），但门控机制已被 **BTEC-Net + RFS-UNet** 占用（见 三·补）。更关键的是**弃权门单调抑制、只能减前景，不可能提升召回**，会把"部分命中"的病灶图直接变成"完全漏诊"。

> **架构方向整体结论**：BUSI 上"换新骨干/新模块"已无新意空间。本仓库真正有价值的方向**不在架构**，而在**归因与判据**（见第四节工作 3）。

### 三·补　图像级「有/无病灶」分类器门控（P4，2026-10 查新 + 实测）

> 命题：把"是否出兜底提示"改由**图像级二分类器**（有/无病灶）决定，而非分割掩膜的 pmax，以消掉 P3 兜底的正常图假阳代价。

| 先例 | 做法 | 与本项关系 |
|---|---|---|
| **BTEC-Net + RFS-UNet**（Cho 等；AUDT 2026 综述 [33]） | 先分类 **normal / abnormal**，**只对 abnormal 图分割**；原文明确"可降低假阳、提升分割精度" | **完全同构**，动机一致 |
| **Two-stage U-Net + SVM**（Front. Bioeng. Biotechnol. 2026） | 分割掩膜全空 → 判为 normal，否则进入第二阶段 | 与当前"空掩膜门控"同构 |
| **WO2026139056A1**（专利） | 分割无病灶 → 不再检测；用二分类决定是否需要检测 | 专利层面先例 |
| **Rad-VLSM**（arXiv:2605.18130） | BLIP-2 定位 → 候选框 → SAM 多候选聚合 + 诊断 | 与 P3 自动提示管线最接近 |
| **Prompt-Free SAM 多任务**（arXiv:2601.05498） | 3 类（benign/malignant/**normal**）+ 无提示 SAM | 同类多任务框架 |
| **选择性预测 / 弃权**（arXiv:2402.10665、2604.13262） | 图像级"不确定即拒绝输出" | 方法学上游，已成熟 |

**判定**：机制**已被占**，**方法级新意不成立**。唯一窄缝是"分类器只作**无框兜底**的触发器"（而非全图预筛）；未检索到完全相同的组合。

**P4 实测（2026-10-18，150ep × 3 种子；`archive/P4_pgbf_2026-10-18/`）**

- **T1 在 n=20 下不可判定**：EfficientNet-B0 全盲命中 **24/24**；合法阈值（val 选、FP=0，τ=0.662）下正常图误报 **4/20**，但 95%CI **8.1–41.6%** 跨过 10% 目标（精确二项 **p=0.133**）——"≤2/20" 这条判据本身无统计功效（要区分 10% vs 20% 需 **~86 张正常图**）。oracle τ=0.80 为 **1/20**（CI 0.9–23.6%，同样宽）。
- **失败在标定与功效，不在信号**：AUC（全盲 vs 正常）= **0.775**（p=0.008）；两类在 0.65–0.85 区间重叠，而验证集仅 20 张正常图，分数上限 0.662 低于测试集 7 张正常图 → val→test 漂移；同时 n=20 的 FP 区间宽达 8–42%。
- **T2/T3 机制有效**：合法 τ=0.662 下 **Dice 0.6768 与 gate off 逐位相同**，正常图 fg **0.1888→0.0378（−80%）**，有前景正常图 **16.7→7.3 张**；oracle τ=0.80 可到 **0.0092 / 5.7 张**（B0 为 0.0036 / 5.3 张）。

**定位**：**不声称组合创新**（T1 不可判定，按预注册规则不升格）；写成"**门控机制有效、判据功效不足**"的证据 + P3 代价修复证据。残余 7.3 张中 5.3 张来自粗模型本就有框的正常图，门控原理上管不到；要压低只能把 presence 前置到全图，即 BTEC-Net / RFS-UNet 的既有机制。

**风险已部分证伪**：分类器对全盲病灶命中 24/24，说明信号在；真正的瓶颈是正常图侧的小样本标定与判据功效。


## 四、本文的主要工作与结论

> 只列三条主要工作：一条方法学、一条有效边界、一条主归因。原“Dice/HD95 解耦”属于评测常识，不作为工作结论，只在结果中作为提醒。

**工作 1（方法学）· 统一协议下的跨范式公平基准与统计判定门槛**
冻结划分 + 同口径指标 + 3 种子 mean±std + 配对 Wilcoxon，把 7 种方法钉在同一测试集上。据此**否定了注意力门控**：Δ=−0.0189（3 种子均值差；逐图配对 −0.0271），p=0.5569；单次训练波动 ±0.04，大于差值；150ep 早停口径下最优轮 72 vs 49，训练预算也未完全对齐。同类工作普遍缺多种子与显著性检验，单次训练的波动足以淹没结论。

**工作 2 · 两条正交轴的有效边界：推理侧增强与损失选择**
- **推理侧**：同一套零成本增强（后处理/TTA/验证集阈值）在监督式上稳定增益（Dice 增益 ≤+0.020；HD95 最大 −38，TransUNet 106.8→96.2），在提示式上**无效甚至有害**（SAM −0.02、MedSAM 崩溃）。给出机理与启用判据。
- **损失侧**：150ep × 3 种子下，Tversky 与 CE+Dice 差距 **≤0.009**（U-Net +0.009、AttU-Net +0.002、UNet++ +0.004），TransUNet 反向 **−0.027**；Boundary 一致有害（**−0.067 / −0.062**）。结论：损失选择影响 ≤0.01 且**模型依赖**，Boundary 是唯一稳健的损失层负结果。

**工作 3（主归因）· 全自动管线的天花板归因：漏检即瓶颈**
同一协议下，监督式**漏检**（低对比病灶占 ~79% FN 像素）直接决定全自动提示管线的天花板：粗模型在 **9%** 的图上不出框 → 该图整条管线失败 → 端到端从有框子集的 **0.70** 降到 **0.65**。据此给出**提示传导律**（MedSAM 偏大安全、偏小危险；定位误差 > 尺度误差）与**改进优先级**：先救“无框硬失败”，再提升粗模型定位精度，最后才是低对比/小目标增强。

> **边界（重要）**：工作 3 是**归因/发现**，**不是新方法**。落地策略（P3 分档提示、P4 presence 门控）的部件**均已被发表**——多框提示 + 不确定性 FN/FP 控制 = **FNPC-SAM**；不确定性引导多提示自适应 = **MedSAM-U**；按复杂度自适应选提示 = **MAUP**；目标判定→多提示 = **CamoSAM2**；“检测器召回=精度天花板” = **Tiny-YOLOSAM**；门控 = **BTEC-Net + RFS-UNet**。故只作工程增益/代价修复，不作新意主张。

### 四·补　P3 新意复核（2026-10，基于 v4 实测：150ep × 3 种子）

> 把 P3 的主张逐条对 **v4 数据（150ep × 3 种子，`archive/P3_v4_2026-10-18/`）**。

| P3 的主张 | v4 实测（150ep × 3 种子） | 判定 |
|---|---|---|
| ① 误差可分四类 | 正确 66.7 / 偏移 19.7 / 尺度错 7.7 / 欠自信 2.7 / 全盲 19.3（病灶 8.0 + 正常 11.3） | ✅ 描述成立 |
| ② 判据能可靠判出类型 | τ_p 精度 **0.35–0.41**；正常图与全盲病灶 pmax 重叠；收紧阈值只降覆盖（92%→52%）、不升精度 | ❌ **无判别力** |
| ③ 定向 > 通用多候选 | 只救缺失 **0.6769** vs 全档都开 **0.6700**，p=**0.069** | ⚠️ 方向对、**接近但未达 0.05** |
| ④ 兜底消除无框硬失败 | **+0.0226，p=0.002，12 好 0 差**，3/3 种子 Δ 为正；无框率 9.0%→0.7% | ✅ **成立且稳健** |
| ⑤ 正常图代价可接受 | 特异度 0.996→0.93（交集）/ 0.81（多数投票） | ❌ 未通过 |

**结论**：P3 作为**方法新意不成立**；作为**归因 / 负结果**成立——工作 3（无框硬失败可回收，且 **3/3 种子稳健**）+ 四条设计准则（阈值判据无效；只有缺失档需要多候选；**全图框兜底零贡献**；正常图代价不可解）。

**升格条件复核**：① 150ep + 3 种子下"定向 > 通用"达 p<0.05 → **未达（p=0.069）**；② 正常图不劣化 → **未达**。⇒ 仍不升格。
**前提风险已排除**：150ep 下全盲病灶 8 张、无框率 **9.0%**，增益仍为 **+0.0226**，且 **3/3 种子为正** → 收益来自机制，而非偶发。

### 四·补2　presence 门控（PGBF）实测：机制有效、标定受限

> 前置判据见 §三·补（全盲 ≥6/8 命中 且 正常图误报 ≤2/20）。完整数据见 `BUSI-算法优化方案.md` §5.4。

| 项 | 实测 | 判定 |
|---|---|---|
| T1 分类器分得开吗 | EffNet-B0：全盲 **24/24** 命中、AUC 0.775（p=0.008）；正常图 **4/20**（val 合法 τ=0.662），95%CI **8.1–41.6%** | ⚠️ **不可判定**（CI 跨 10%，p=0.133） |
| T1 是信号问题还是标定问题 | 测试集 oracle τ=0.80 → 8/10 命中 + **1/20** 误报 | 信号够，**标定不够** |
| T2 门控后 Drop 吗 | τ=0.662：Dice **0.6768**（与 gate off 逐位相同） | ✅ 不降 |
| T3 代价降多少 | 正常图 fg **0.1888 → 0.0378（−80%）**；oracle τ 可到 0.0092 | ✅ 显著下降 |
| 残留假阳来自哪 | τ=0.662 后仍有 **7.3/20** 正常图有前景，其中 **5.3 张是"粗模型本来就出框"**（不在 blind 分支）→ 门控原理上管不到 | 结构性 |

**判定**：按预注册规则 **T1 不可判定 ⇒ PGBF 不作「新方法」主张**；**机制本身有效**（免费降 80% 假阳面积），限制来自"20 张正常图既估不准阈值、也没有统计功效"（要判定需 **≥86 张**）。写作口径建议：

- **可写**：`无框兜底可回收端到端 +0.023（p=0.002，3/3 种子）`；`presence 门控可把代价压到 1/5 而不损 Dice`；`4/20 与 10% 目标在 n=20 下不可区分（95%CI 8–42%）`；`残留假阳是二分类分割头的信息上限`。
- **不可写**：presence gate 机制为新方法；"误差类型诊断"为新方法；正常图代价已被解决。

## 五、建议的论文主线

> **问题**：BUSI 上方法众多但划分/口径不一，结论不可比，且普遍缺统计检验。
> **方法**：建立统一评估协议 + 统计判定门槛；系统评测"重训侧损失（Tversky/Boundary）"与"推理侧增强（后处理/TTA/阈值）"两条正交轴，并对**漏检 → 自动提示**的传导链做归因。
> **发现**：① 推理增强存在**跨范式适用边界**（监督式有效、提示式有害）；评测上同时报告 HD95 作为辅助指标（常识性建议，不作为工作结论）；② **损失选择的影响 ≤0.01 且模型依赖**——150ep 下 Tversky 在轻量模型 ≥ CE+Dice、Boundary 一致有害，但重模型 **TransUNet 上 Tversky 反降（−0.027）**（工作 2）；③ 注意力门控不显著（工作 1）；④ **全自动提示的天花板由粗模型漏检决定**（9% 无框硬失败，端到端拉低 ~0.05）（工作 3）。
> **对照**：与 KD SAM / FA-SAM / VESSA 等已有工作明确区分（见 一/二），不重复其主张；自动提示只做"瓶颈归因 + 分档提示决策"，不做管线（见 四·工作 3），也不做分类器门控兜底（= BTEC-Net / RFS-UNet，见 三·补）。
