# BUSI 分割 · 优化方案（诊断 · 方案 · 实现 · 执行）

> 实测数值见 `docs/七种模型对比.md`（第三/四/七节）；充分训练对照见 `docs/BUSI-P1-充分训练.md`；**查新与新意定位见 `docs/BUSI-查新与新意.md`**。
> 判定门槛：改动需 > 3 种子标准差（监督式 ≈ 0.02）**且** Wilcoxon p < 0.05 才算有效。

## 一、问题诊断（实测）

| 组别 | 最佳方法 | Dice(病灶) | 召回 | HD95 |
|---|---|---|---|---|
| 监督式（全自动） | TransUNet | 0.7002 | 0.7405 | 106.8 |
| 提示式（单点） | BUSSAM | 0.8361 | 0.8557 | 35.0 |
| 提示式（GT 框） | MedSAM | 0.9124 | 0.9150 | 15.4 |

**四个症结**：

1. **漏检**：监督式召回 ~0.69–0.75，BUSSAM 0.856。监督式的召回是最大提升空间。**→ P1 表明其中相当一部分是欠拟合：延长训练即可抬升召回（见 `docs/BUSI-P1-充分训练.md`）。**
2. **边界差**：监督式 HD95 107–131，提示式仅 15–35 —— 差一个量级，且不是位置错而是轮廓糊。
3. **结构微调无效**：U-Net → Attention U-Net Δ=−0.0189（3 种子均值差）、p=0.557，**不显著**。
4. **提示依赖**：点 → 框使 MedSAM 从 0.1247 跃至 0.9124，**提示质量是提示式方法的决定性变量**。

> **补充（零成本诊断，详见第二节）**：漏检**不是**由"正常图训练"造成，而是**低对比病灶**主导（占 ~79% FN 像素）；且监督式的漏检**直接封顶**全自动提示管线——粗模型在 **8–11%** 的图上完全不出框，把端到端从有框子集的 0.70 拖到 0.62–0.65。

**实测摘要**（完整见 `docs/七种模型对比.md` 第七节）：

- **A 组**（后处理/TTA/阈值）：对全部 4 个监督式稳定有效（Dice 增益 **≤0.020**，boundary 模型 HD95 降 ~38）；**对提示式无效甚至有害**。
- **B 组**（损失，24ep）：Tversky 对轻量模型有效（U-Net **+0.036**）、对 UNet++ **有害**（−0.023）；**Boundary 一致有害**（−0.05~−0.08）。
- **P1 校正（150ep + 验证集早停 + 最优轮回滚，3 种子）**：对轻量模型 **训练预算主导** —— 10 个配置中 9 个提升（**+0.016 ~ +0.074**，最优轮落在 **23–81**，原 24ep **严重欠拟合**）。充分训练后 **Tversky 对轻量模型全面 ≥ CE+Dice**（UNet++ 由 −0.023 **反转为 +0.004**；U-Net +0.009、AttU-Net +0.002），而 **Boundary 仍一致偏差**（U-Net −0.067、AttU-Net −0.062）；**例外：TransUNet + Tversky 反而变差（−0.023，重跑后最优轮仅 19–30、早早饱和）** → 结论为**模型依赖**。→ **贡献 3 已改写为"训练预算 ≫ 损失选择（轻量模型）；重模型 Tversky 不适用"**（见 `BUSI-查新与新意.md`）。
- **全局最优**：24ep 下 TransUNet + tversky + A3 = **0.6992**；零重训最优 AttU-Net + ce_dice + A2+A1+A3 = **0.6508**。**150ep 后最优 = TransUNet + CE+Dice + A2+A1+A3 = 0.7087**（HD95 96.2）。

### 2.1 监督式漏检的来源分解

对 **U-Net / TransUNet**（变体 A2+A1+A3）的逐图像素统计做分解（召回=TP/(TP+FN)，完全漏检=TP=0）。

| 模型 | 维度 | 分桶 | 张数 | 召回 | 完全漏检率 | Dice | FN 像素占比 |
|---|---|---|---|---|---|---|---|
| U-Net | 尺寸 | 小（相对面积≤4.0%） | 32 | 0.612 | **34.4%** | 0.508 | 7.8% |
| U-Net | 尺寸 | 中 | 32 | 0.643 | 18.8% | 0.646 | 26.0% |
| U-Net | 尺寸 | 大（>9.9%） | 32 | 0.743 | 9.4% | 0.743 | 66.2% |
| U-Net | 对比度 | **低对比** | 32 | **0.306** | **46.9%** | 0.342 | **79.3%** |
| U-Net | 对比度 | 中对比 | 32 | 0.799 | 12.5% | 0.731 | 12.3% |
| U-Net | 对比度 | 高对比 | 32 | 0.894 | 3.1% | 0.825 | 8.3% |
| TransUNet | 尺寸 | 小 | 32 | 0.715 | 15.6% | 0.674 | 5.2% |
| TransUNet | 尺寸 | 中 | 32 | 0.674 | 15.6% | 0.689 | 24.0% |
| TransUNet | 尺寸 | 大 | 32 | 0.707 | 9.4% | 0.722 | 70.8% |
| TransUNet | 对比度 | **低对比** | 32 | **0.352** | **34.4%** | 0.385 | **78.8%** |
| TransUNet | 对比度 | 中对比 | 32 | 0.839 | 6.2% | 0.813 | 12.4% |
| TransUNet | 对比度 | 高对比 | 32 | 0.905 | **0.0%** | 0.886 | 8.7% |

**结论**
1. **低对比是漏检的首要来源**：低对比三分位的病灶贡献了 **~79% 的漏检像素**，召回仅 0.31–0.35，且 **35–47% 完全漏检**；高对比几乎不漏（完全漏检 0–3%）。
2. **小病灶更易"整个漏掉"**：小病灶完全漏检率 16–34%，约为大病灶（9%）的 2–4 倍；但因其像素少，对总 FN 像素的贡献反而不高（5–8%）。
3. 大病灶贡献 FN 像素占比最高（66–71%）**只是因为像素基数大**，其召回其实最好（0.71–0.74）。
4. **对策**：把资源投到"低对比 + 小病灶"—— 对比度/增益增强、低对比感知损失、**Tversky 损失**（Boundary 已证有害，见 3.1）、以及针对小目标的深监督/多尺度（UNet++ 类）。

### 2.2 粗模型框质量 → 自动提示最终 Dice（传导曲线）

用**已训监督式模型**出框（最大连通域外接框）→ 喂 **MedSAM / SAM** 精修；另用 GT 框按尺度缩放构造质量梯度作参照。

> **口径注意**：GT 框尺度行覆盖全部 **96** 张病灶图；**auto 行只覆盖"有框子集"（U-Net **88** / UNet++ **85**）**——脚本对无框图直接 `continue`，不计入（见 `src/diag_zero_cost.py`）。auto 框用的是 `viz_unet_seed0.pth` / `viz_unetpp_seed0.pth`。

| 框来源 | n | 框 IoU | MedSAM Dice | SAM Dice |
|---|---|---|---|---|
| GT 框（oracle） | 96 | 1.000 | **0.9124** | **0.8185** |
| GT ×1.15 | 96 | 0.756 | 0.9035 | 0.7760 |
| GT ×0.85 | 96 | 0.722 | 0.7735 | 0.7770 |
| GT ×1.30 | 96 | 0.592 | 0.8142 | 0.7116 |
| **auto（U-Net）** | **88** | **0.587** | **0.7044** | 0.6549 |
| **auto（UNet++）** | **85** | **0.565** | **0.6975** | 0.6419 |
| GT ×0.70 | 96 | 0.490 | 0.5600 | 0.6002 |
| GT ×1.50 | 96 | 0.444 | 0.6684 | 0.6111 |

**端到端修正**（把无框的 8–11 张按协议记 Dice=0，分母回到 96）：

| 管线 | 有框子集 | **端到端（96 张）** |
|---|---|---|
| U-Net → MedSAM | 0.7044（n=88） | **0.6457** |
| U-Net → SAM | 0.6549（n=88） | 0.6003 |
| UNet++ → MedSAM | 0.6975（n=85） | **0.6176** |
| UNet++ → SAM | 0.6419（n=85） | 0.5683 |

图：`results/diag_box_curve.png`（曲线 + auto 框散点）。

**结论**
1. **MedSAM 对"框偏大"鲁棒、对"框偏小"敏感**：×1.15（IoU 0.756）仍有 0.9035，而 ×0.85（IoU 0.722）只有 0.7735 —— **同 IoU 下偏大远好于偏小**。→ 自动出框应**宁可外扩 k%**。
2. **定位误差比尺度误差更伤**：auto 框 IoU 0.587（≈ 与 ×1.30 的 0.592 同水平）却只有 **0.7044**，明显低于 ×1.30 的 0.8142 —— 说明 auto 框**不是同心缩放**，而是**整体偏移/形状不符**，惩罚更大。
3. **粗模型"不出框"直接等价于漏检，且是整条链条上唯一不可恢复的失败**：96 张中有 **8–11 张**粗模型无前景（auto n=88/85），与 2.1 节"低对比/小病灶完全漏检"完全吻合。
4. **全自动管线实测量级（修正口径）**：auto 框 → MedSAM 在**有框子集**上为 **0.7044（n=88）/ 0.6975（n=85）**；但把无框图按协议记 Dice=0 后，**端到端仅 0.6457 / 0.6176**。相对**粗模型自身**（U-Net + A2+A1+A3 ≈ 0.6293）净增益 **+0.016**，**低于**监督式最优 **0.6992**（差 0.054）。
   → 早前"零人工提示已达监督式水平"的说法**不成立**；真实结论是"**精修器有小幅增益，但端到端被 8–11% 的无框硬失败拖到 0.62–0.65**"。
5. **分母不一致**：scale 曲线为 n=96、auto 点为 n=88/85，二者画在同一张图上时须分别标注，否则不可直接比较。

### 2.3 由此得到的改进优先级（零成本诊断的直接产物）

| 优先级 | 动作 | 依据 |
|---|---|---|
| 1 | 粗模型"无前景 → 多候选框 / 密集提示兜底" | **8–11% 图无框，端到端吃掉 ~5.4 Dice 点（0.7044→0.6457）**——量级最大的一处损失 |
| 2 | 自动框**外扩 10–20%** | MedSAM 对偏大鲁棒、对偏小敏感 |
| 3 | 提升粗模型**定位精度**（而非仅 IoU） | 同 IoU 下 auto 框 Dice 更低 |
| 4 | 低对比增强 + 小病灶深监督 | 低对比占 79% FN 像素、小病灶完全漏检率 34% |

## 四、待做方案的实施细节

### 4.1 P3　误差类型感知的定向提示纠正（新意落点）

> **一句话**：不用"标量置信度"分档，而是**先诊断粗掩膜的误差类型**（缺失 / 偏移 / 尺度错 / 正确），再**按误差类型定向生成候选提示**——分档依据与候选生成是同一件事的两半。
> **机理依据（本仓库实测）**：§2.2 已证 **定位误差 > 尺度误差**（同 IoU 下偏大远好于偏小）。故"按误差类型定向"是**由机理反推判据**，而非拍脑袋选阈值。

**目标**：把端到端基线 **0.6457**（单框 → MedSAM）提升，并证明"**定向 > 通用**"。
**落点**：新增 `src/diag_tier_prompt.py`，复用 `src/eval_prompt_quality.py` 的 `sup_box_fn / scale_box / medsam_box / sam_box` 与 `src/busi_common.py` 的指标。**零重训。**

**① 误差类型诊断（无 GT，只用粗模型输出；阈值仅在验证集定）**

| 类型 | 判据 | 定向候选 |
|---|---|---|
| **缺失** | 前景峰值 < τ_p 或无连通域（`box is None`） | 降阈值取弱连通域 / 密集点 |
| **偏移** | 粗框中心 vs 概率图重心偏离 > τ_d | **平移**粗框（±k%） |
| **尺度错** | 框面积 / 高置信区面积比偏离 1 > τ_s | **多尺度**候选（优先**外扩**） |
| **正确** | 以上均不触发 | 单框 + 轻外扩 |

**② 定向候选 → 精修 → 集成**：每个候选喂 MedSAM；**并集**（保召回）或按一致性选（val 上定）。

**③ 消融矩阵（单变量，主证据）**

| 编号 | 配置 | 隔离什么 |
|---|---|---|
| B0 | 单框 s=1.0 → MedSAM | 基线 **0.6457** |
| B1 | 全局外扩 ×1.15 | 外扩增益 |
| B2 | **通用**多候选（不分误差类型） | 通用基线 |
| **B3** | **误差类型定向**（诊断 → 定向候选） | **主结果**；须 **B3 > B2** 才证明"定向"有效 |
| B4 | B3 + 多尺度集成 | 是否再加分 |
| B5 | B3 但"缺失/无病变"不弃权 | 弃权的价值 |

每项统一报：**端到端 Dice（96，无框记 0）+ 无框率 + 病灶 Dice + 正常图 `fg_ratio`**。

**④ 成功判据**：**B3 > max(B0, B2)**（定向胜过通用与基线）且 **B3 ≥ B1**；正常图假阳不劣化。
**⑤ 产出**：`results/tier_prompt.json`；图——误差类型分布 + 各类型增益分解 + 阈值敏感性。

> **查新边界**：通用多候选 + 不确定性过滤 = **FNPC-SAM / 0-SAM-U**；按复杂度自适应选提示 = **MAUP**；置信度阈值校正 = **ICCV2025W**；粗掩膜误差校正 = **CoSAM**；提示类型选择 = **BiPrompt-SAM**。**未检索到"误差类型诊断 → 定向候选"这一组合**——本方案新意只在此，其余部件降为实现细节。
