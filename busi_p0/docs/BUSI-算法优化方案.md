# BUSI 分割 · 优化方案（问题诊断 · 方案设计 · 实现 · 新意定位）

> **本文档只做四件事**：诊断瓶颈、列出已做/待做方案、说明实现、定位新意。
> **全部实测数值见 `docs/七种模型对比.md`（第三/四/五节）**，此处只引用结论，不重复数据表。
> 判定门槛：改动需 > 3 种子标准差（监督式 ≈ 0.02）**且** Wilcoxon p < 0.05 才算有效。

## 一、问题诊断（实测）

| 组别 | 最佳方法 | Dice(病灶) | 召回 | HD95 |
|---|---|---|---|---|
| 监督式（全自动） | TransUNet | 0.6911 | 0.7226 | 111.4 |
| 提示式（单点） | BUSSAM | 0.8361 | 0.8557 | 35.0 |
| 提示式（GT 框） | MedSAM | 0.9124 | 0.9150 | 15.4 |

**四个症结**：

1. **漏检**：监督式召回 ~0.71–0.72，BUSSAM 0.856。监督式的召回是最大提升空间。
2. **边界差**：监督式 HD95 111–160，提示式仅 15–35 —— 差一个量级，且不是位置错而是轮廓糊。
3. **结构微调无效**：U-Net → Attention U-Net Δ=−0.0004、p=0.34，**不显著**。注意力门控类改动在本数据规模下已被反证。
4. **提示依赖**：提示式精度高但需提示；点 → 框使 MedSAM 从 0.1247 跃至 0.9124，说明**提示质量是提示式方法的决定性变量**。

## 二、优化方案

> 只保留两类：**已做**（有实测结论可引用）与**待做**（能支撑已主张的贡献，且成本可控）。
> 已排除的方向不再列入：结构改进（被 p=0.34 反证）、大模型复用 C1/C2（属已有工作，见第五节）、
> 数据增强 E、分辨率 B4（跨分辨率会破坏协议的单变量控制）、C3 集成（无证据支撑）。

### 2.1 已做的优化方案

| 编号 | 方案 | 目标 | 实测结论 |
|---|---|---|---|
| A1 | 后处理：填洞 + 最大连通域 + 面积阈值(>0.1%) | 降 HD95/ASD、降正常图假阳性 | 监督式有效；提示式有害 |
| A2 | TTA：多尺度 {0.75,1.0,1.25} × 水平翻转，概率域平均 | 降方差、稳 Dice | 监督式普遍有效（TransUNet 仅用翻转） |
| A3 | 前景阈值搜索（0.5 → 验证集最优） | 平衡 P/R | 有效；boundary 模型增益最大(+0.037) |
| B1 | Tversky loss (α=0.3, β=0.7)，CE+Tversky | 直接提召回 | 轻量模型有效(U-Net +0.036)；UNet++ 有害(−0.023) |
| B2 | CE + Dice + Boundary loss（有向距离图） | 优化边界 | **一致有害（−0.05~−0.08），已放弃** |

> 数值见 `docs/七种模型对比.md` 第五节；代码见第四节。

## 三、实测结论（摘要）

> 完整数据见 `docs/七种模型对比.md` 第五节。

- **A 组**：对**全部 4 个监督式**稳定有效（Dice **+0.011~0.037**），且 **HD95 大幅下降**（UNet++ 141→117、U-Net(boundary) 181→147、AttU-Net(boundary) 193→161）；**对提示式无效甚至有害**（SAM −0.02、MedSAM 崩溃至 0.01）。
  → 机理：监督式的密集预测存在孤立假阳与孔洞，后处理可修；提示式输出已是单一干净前景，**面积门限反而误删小病灶**。
- **B 组**：**Tversky 对轻量模型有效**（U-Net +0.036、AttU-Net +0.015），**对 UNet++ 有害**（−0.023），对 TransUNet 略正（+0.014）；**Boundary 单独使用一致有害**（−0.05~−0.08），与"优化边界"的预期**相反**。
- **全局最优**：**TransUNet + tversky + A3 = 0.6992**（HD95 105）；零重训代价下最优为 **AttU-Net + ce_dice + A2+A1+A3 = 0.6508**。

**两条反直觉但有价值的发现**：
1. **A 组的收益主要落在距离指标而非重叠指标**：UNet++ 的 Dice 仅 +0.015，HD95 却降 24 —— 说明"面积重叠"与"边界质量"是解耦的，只用 Dice 评估会低估推理侧增强的价值。
2. **优化项的收益依赖模型容量**：同一 Tversky 在 U-Net 上 +0.036，在 UNet++ 上 −0.023。**损失函数不是"加了就好"**，存在有效边界。

## 四、实现与运行

### 4.1 代码落点
| 编号 | 实现位置 | 说明 |
|---|---|---|
| A1 | `src/busi_common.py` → `postprocess_mask()` | 填洞 → 最大连通域 → 面积闸门(<0.1% 判空) |
| A2 | `src/eval_postproc.py` → `prob_map_original_res(tta=True)` | 多尺度 × 翻转，概率域平均 |
| A3 | `src/eval_postproc.py` → `search_threshold()` | **仅用验证集**搜阈值，目标=病灶图平均 Dice |
| B1 | `src/train_supervised.py` → `tversky_loss()` | `--loss tversky`（CE+Tversky） |
| B2 | `src/train_supervised.py` → `boundary_loss()` | `--loss boundary`（CE+Dice+λ·Boundary，有向距离图） |

### 4.2 运行
```bash
# B 组：重训（基线 ce_dice 文件名不变，不覆盖已有结果）
python train_supervised.py --model unet --size 128 --gray --epochs 24 --seed 0 --loss tversky  --save-ckpt
python train_supervised.py --model unet --size 128 --gray --epochs 24 --seed 0 --loss boundary --save-ckpt

# A 组：在已有权重上推理，一次输出全部 8 个组合
python eval_postproc.py --ckpt results/ckpt/unet_s128g_e24_seed0.pt --model unet --size 128 --gray --tta
```
`eval_postproc.py` 输出 `results/postproc_<tag>_seed<k>.json`，含各变体的
`dice_lesion / iou_lesion / precision / recall / hd95 / asd` 与验证集搜出的阈值。

### 4.3 报告口径
- **主表不改**：A 组属推理侧附加项，按协议单独成表，不并入"统一后处理=无"的主结果。
- **阈值只用验证集**：A3 在 val 上搜，测试集仅用于最终评分，杜绝调参泄漏。
- **单变量原则**：B1 = Dice→Tversky；B2 = CE+Dice 加一项。每次只动一个变量。
- **TransUNet 的 TTA 只用翻转**：多尺度会破坏其固定位置编码。

## 五、相关工作与新意定位（查新结论）

> **重要**：原方案中作为"创新方向"的 C1/C2，经文献核查**均已被发表**，不能再作为新意主张。

### 5.1 查新结果

| 本文设想 | 已有工作 | 重合度 |
|---|---|---|
| C1 知识蒸馏（大模型 → 轻量模型） | **KD SAM** (arXiv:2501.16740, 含乳腺超声)、ProtoSAM-2D (SPIE 2025)、De-LightSAM (arXiv:2407.14153)、Embed-MedSAM (NPJ Digit Med 2025)、VESSA 相关 (NeurIPS 2025) | 高——机制、损失、评测域均重合 |
| C2 粗模型出框 → 提示式精修 | **FA-SAM** (arXiv:2507.17281, 流程逐步骤重合)、**SemiSAM** (arXiv:2312.06316)、SemiSAM+、**SAM-Match** (Med Phys 2025, **含 BUSI**)、DFG auto-prompting (IEEE TMI 2025)、Self-Prompting SAM (IET CV 2025) | 极高 |
| C1+C2 闭环（预测反哺提示） | **VESSA** (arXiv:2511.19759)、SAM-Match；更早的 prompt-in-the-loop 见 **EdgeSAM** (arXiv:2312.06660) | 极高 |

### 5.2 因此本文**不**主张
- ❌ "从 SAM/BUSSAM 蒸馏出轻量分割模型"（= KD SAM 等）
- ❌ "用粗分割模型自动生成提示驱动 SAM"（= FA-SAM / SemiSAM）
- ❌ "提示与预测闭环反哺"（= VESSA / SAM-Match）
- ❌ "注意力门控改进分割"（本仓库 p=0.34 已自证无效）

> 以上四项**已从第二节的方案清单中移除**，不再投入。

### 5.3 本文可主张的新意

**贡献 1（方法学）· 统一协议下的跨范式公平基准**
冻结划分 + 同口径指标 + 多种子 mean±std + 配对 Wilcoxon，把 7 种方法钉在同一测试集上。据此**否定了注意力门控**（Δ=−0.0004，p=0.3394）——同类工作普遍缺多种子与显著性检验，单次训练的波动（±0.02）足以淹没结论。

**贡献 2（最有把握）· 推理侧增强的跨范式适用边界 + 适用性判据**
同一套零成本推理增强（后处理/TTA/验证集阈值）在**监督式**上稳定增益（+0.011~0.037，HD95 最多降 35），在**提示式大模型**上**无效甚至有害**（SAM −0.02、MedSAM 崩溃）。给出机理（预测稀疏度/空掩膜比例/形态复杂度）与**是否启用的判据**，可做成"即插即用模块 + 准则"的完整故事。

**贡献 3 · 损失函数的有效边界**
Tversky 的收益强烈依赖模型容量（U-Net **+0.036** vs UNet++ **−0.023**）；**Boundary 单独使用一致有害**。给出小数据超声分割上"损失有效性"的对照证据与适用条件，比"只报涨点"信息量更大。

**贡献 4 · 重叠指标与边界指标的解耦**
A 组对 Dice 的增益有限（+0.015）但对 HD95 显著（−24）。说明只报 Dice 会**系统性低估**推理侧增强；建议分割评测同时报告距离类指标。

### 5.4 建议的论文主线
> **问题**：BUSI 上方法众多但划分/口径不一，结论不可比，且普遍缺统计检验。
> **方法**：建立统一评估协议 + 统计判定门槛；系统评测"重训侧损失（Tversky/Boundary）"与"推理侧增强（后处理/TTA/阈值）"两条正交轴。
> **发现**：① 推理增强存在**跨范式适用边界**（监督式有效、提示式有害）；② 损失存在**容量依赖的有效边界**；③ 注意力门控不显著；④ Dice 与 HD95 解耦。
> **对照**：与 KD SAM / FA-SAM / VESSA 等已有工作明确区分（见 5.1/5.2），不重复其主张。

## 六、待做方案的实施细节

### 6.1 P1　充分训练（排除欠拟合）

当前所有监督式均为 **24 epoch**。若模型欠拟合，则"Boundary 有害""Tversky 对 UNet++ 有害"可能只是**训练不足的表现**，而非损失本身的问题——这会直接动摇贡献 3。

- **做法**：`--epochs 100~150`，按验证集 Dice 早停并回滚最优轮（`train_supervised.py` 已有 best-val 回滚逻辑，只需延长轮数）。
- **范围**：U-Net / AttU-Net × {ce_dice, tversky, boundary}，3 种子。
- **判据**：若延长后 Boundary 仍低于 ce_dice、Tversky 在 UNet++ 上仍为负 → 结论成立；**若反转，则须改写贡献 3**。
- **成本**：约 10 min。

### 6.2 P2　提示质量 → 最终精度鲁棒性曲线

贡献 2 主张"推理侧增强存在跨范式边界"，但目前只证明了**提示式不适用**，没有量化它**依赖什么**。本条补上"提示式对提示误差的敏感度"，把边界条件说完整。

1. 用已训好的监督式模型出框（U-Net / UNet++）→ 最大连通域外接框（可外扩 k%）；
2. 对 GT 框做**抖动**（缩放 ±5/10/20%、平移、掺入无关区域），构造框质量梯度；
3. 以 **MedSAM（框 0.9124）/ SAM（框 0.8185）** 为精修器，画 `最终 Dice ~ 框与 GT 的交并比(IoU)` 曲线（2~3 个提示模型 × 5 档质量）。

- **成本**：5 档 × 96 图 × 2~3 模型 ≈ 20 min。
- **风险**：正常图可能出假框 → 用"前景占比阈值"跳过。
- **产出**：一张曲线图（论文图），支撑贡献 2 的"适用性判据"。

### 6.3 执行顺序

| 顺序 | 内容 | 理由 |
|---|---|---|
| 1 | P1 充分训练 | 先钉死 B 组结论，避免后续归因被推翻 |
| 2 | P2 提示质量曲线 | 性价比最高的补充证据 |
