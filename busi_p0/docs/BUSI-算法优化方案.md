# BUSI 分割 · 优化方案（诊断 · 方案 · 实现 · 执行）

> 实测数值见 `docs/七种模型对比.md`（第三/四/五节）；漏检与自动提示归因见 `docs/BUSI-零成本诊断.md`；**查新与新意定位见 `docs/BUSI-查新与新意.md`**。
> 判定门槛：改动需 > 3 种子标准差（监督式 ≈ 0.02）**且** Wilcoxon p < 0.05 才算有效。

## 一、问题诊断（实测）

| 组别 | 最佳方法 | Dice(病灶) | 召回 | HD95 |
|---|---|---|---|---|
| 监督式（全自动） | TransUNet | 0.6911 | 0.7226 | 111.4 |
| 提示式（单点） | BUSSAM | 0.8361 | 0.8557 | 35.0 |
| 提示式（GT 框） | MedSAM | 0.9124 | 0.9150 | 15.4 |

**四个症结**：

1. **漏检**：监督式召回 ~0.71–0.72，BUSSAM 0.856。监督式的召回是最大提升空间。
2. **边界差**：监督式 HD95 111–160，提示式仅 15–35 —— 差一个量级，且不是位置错而是轮廓糊。
3. **结构微调无效**：U-Net → Attention U-Net Δ=−0.0004、p=0.34，**不显著**。
4. **提示依赖**：点 → 框使 MedSAM 从 0.1247 跃至 0.9124，**提示质量是提示式方法的决定性变量**。

> **补充（零成本诊断，`docs/BUSI-零成本诊断.md`）**：漏检**不是**由"正常图训练"造成，而是**低对比病灶**主导（占 ~79% FN 像素）；且监督式的漏检**直接封顶**全自动提示管线——粗模型在 **8–11%** 的图上完全不出框，把端到端从有框子集的 0.70 拖到 0.62–0.65。

**实测摘要**（完整见 `docs/七种模型对比.md` 第五节）：

- **A 组**（后处理/TTA/阈值）：对全部 4 个监督式稳定有效（Dice **+0.011~0.037**，HD95 最多降 35）；**对提示式无效甚至有害**。
- **B 组**（损失，24ep）：Tversky 对轻量模型有效（U-Net **+0.036**）、对 UNet++ **有害**（−0.023）；**Boundary 一致有害**（−0.05~−0.08）。
- **P1 校正（150ep + 验证集早停 + 最优轮回滚，3 种子）**：**训练预算才是主导因素** —— 全部配置 **+0.016 ~ +0.074**，最优轮落在 **29–81**（原 24ep **严重欠拟合**）。充分训练后 **Tversky 全面 ≥ CE+Dice**（UNet++ 由 −0.023 **反转为 +0.004**；U-Net +0.009、AttU-Net +0.002），而 **Boundary 仍一致偏差**（U-Net −0.067、AttU-Net −0.062）。→ **贡献 3 已改写为"训练预算 ≫ 损失选择"**（见 `BUSI-查新与新意.md`）。
- **全局最优**：TransUNet + tversky + A3 = **0.6992**；零重训最优 AttU-Net + ce_dice + A2+A1+A3 = **0.6508**。

### 2.1 已做的优化方案

| 编号 | 方案 | 目标 | 实测结论 |
|---|---|---|---|
| A1 | 后处理：填洞 + 最大连通域 + 面积阈值(>0.1%) | 降 HD95/ASD、降正常图假阳性 | 监督式有效；提示式有害 |
| A2 | TTA：多尺度 {0.75,1.0,1.25} × 水平翻转，概率域平均 | 降方差、稳 Dice | 监督式普遍有效（TransUNet 仅用翻转） |
| A3 | 前景阈值搜索（0.5 → 验证集最优） | 平衡 P/R | 有效；boundary 模型增益最大(+0.037) |
| B1 | Tversky loss (α=0.3, β=0.7)，CE+Tversky | 直接提召回 | 24ep：轻量模型有效(U-Net +0.036)、UNet++ 有害(−0.023)；**P1 校正后全面 ≥ ce_dice** |
| B2 | CE + Dice + Boundary loss（有向距离图） | 优化边界 | **一致有害（−0.05~−0.08）；P1 校正后仍偏差（−0.06~−0.07），已放弃** |

## 三、实现与运行

### 3.1 代码落点

| 编号 | 实现位置 | 说明 |
|---|---|---|
| A1 | `src/busi_common.py` → `postprocess_mask()` | 填洞 → 最大连通域 → 面积闸门(<0.1% 判空) |
| A2 | `src/eval_postproc.py` → `prob_map_original_res(tta=True)` | 多尺度 × 翻转，概率域平均 |
| A3 | `src/eval_postproc.py` → `search_threshold()` | **仅用验证集**搜阈值，目标=病灶图平均 Dice |
| B1 | `src/train_supervised.py` → `tversky_loss()` | `--loss tversky`（CE+Tversky） |
| B2 | `src/train_supervised.py` → `boundary_loss()` | `--loss boundary`（CE+Dice+λ·Boundary，有向距离图） |
| P2 | `src/eval_prompt_quality.py`、`src/diag_zero_cost.py` | 提示质量曲线 + 零成本诊断 |
| P3 | `src/diag_tier_prompt.py`（待建） | 分档提示策略 |

### 3.2 运行

```bash
# B 组：重训（基线 ce_dice 文件名不变，不覆盖已有结果）
python train_supervised.py --model unet --size 128 --gray --epochs 24 --seed 0 --loss tversky  --save-ckpt
python train_supervised.py --model unet --size 128 --gray --epochs 24 --seed 0 --loss boundary --save-ckpt

# A 组：在已有权重上推理，一次输出全部 8 个组合
python eval_postproc.py --ckpt results/ckpt/unet_s128g_e24_seed0.pt --model unet --size 128 --gray --tta
```

`eval_postproc.py` 输出 `results/postproc_<tag>_seed<k>.json`，含各变体的
`dice_lesion / iou_lesion / precision / recall / hd95 / asd` 与验证集搜出的阈值。

### 3.3 报告口径

- **主表不改**：A 组属推理侧附加项，按协议单独成表，不并入"统一后处理=无"的主结果。
- **阈值只用验证集**：A3 在 val 上搜，测试集仅用于最终评分，杜绝调参泄漏。
- **单变量原则**：B1 = Dice→Tversky；B2 = CE+Dice 加一项。每次只动一个变量。
- **TransUNet 的 TTA 只用翻转**：多尺度会破坏其固定位置编码。

## 四、待做方案的实施细节

### 4.1 P1　充分训练（排除欠拟合）— ✅ 已完成

原监督式均为 **24 epoch**。若欠拟合，则"Boundary 有害""Tversky 对 UNet++ 有害"可能只是**训练不足**，会动摇贡献 3。

- **做法**：`--epochs 150` + 验证集 Dice 早停（patience 15）+ 最优轮回滚（新增 `--early-stop / --min-epochs`）；损失/优化器/增强与基线一致；3 种子。
- **范围**：U-Net / AttU-Net × {ce_dice, tversky, boundary} **＋ UNet++ × {ce_dice, tversky}**（UNet++ 的 Tversky 结论必须用它验证）。

| 模型 | 损失 | 24ep | 150ep | Δ | 最优轮 |
|---|---|---|---|---|---|
| U-Net | ce_dice | 0.6137 | **0.6875** | **+0.074** | 72 |
| U-Net | tversky | 0.6492 | **0.6966** | +0.047 | 58 |
| U-Net | boundary | 0.5628 | 0.6210 | +0.058 | 81 |
| AttU-Net | ce_dice | 0.6292 | 0.6689 | +0.040 | 49 |
| AttU-Net | tversky | 0.6444 | 0.6712 | +0.027 | 42 |
| AttU-Net | boundary | 0.5512 | 0.6073 | +0.056 | 68 |
| UNet++ | ce_dice | 0.6265 | 0.6429 | +0.016 | 29 |
| UNet++ | tversky | 0.6039 | **0.6470** | **+0.043** | 42 |

- **判据结果**：① **Boundary 仍低于 ce_dice**（−0.067 / −0.062）→ "Boundary 有害"**成立**；② **Tversky 在 UNet++ 上由 −0.023 反转为 +0.004** → "Tversky 对 UNet++ 有害"**被推翻**（原为欠拟合假象）→ **贡献 3 已改写**。
- **附带发现**：150ep 的 U-Net（0.6875 / 0.6966）已追平 24ep 的 TransUNet（0.6958）——监督式内部"结构差距"也被训练预算抹平。
- 产物：`results/p1_summary.md`、`p1_summary.json`、`p1_*.json`（24 个）；文档见 `docs/七种模型对比.md` §7.3。
- **成本实况**：约 70 min（UNet++ 256-RGB 为主；3 路并行为负优化，已改串行）。

### 4.2 P2　提示质量 → 最终精度曲线（✅ 已完成）

> 已完成，产物见 `docs/BUSI-零成本诊断.md` 第二节（含**口径修正**：auto 行为有框子集 n=88/85，端到端 0.62–0.65）。

### 4.3 P3　分档提示策略（新主贡献）

**目标**：把端到端基线 **0.6457**（单框 → MedSAM）提升，并证明增益来自**分档决策**本身。
**落点**：新增 `src/diag_tier_prompt.py`，复用 `src/eval_prompt_quality.py` 的 `sup_box_fn / scale_box / medsam_box / sam_box` 与 `src/busi_common.py` 的指标。**零重训。**

1. **判据信号**：逐图取 `fg_ratio`、`prob_max`、`cc_area_rel`（把 `sup_box_fn` 拆出一版返回这些量）；**阈值只在验证集定**（同 A3 原则）。
2. **三档策略**：

| 档 | 判据 | 提示 | 精修 |
|---|---|---|---|
| H 确定有 | `fg_ratio>τ_a` 且 `prob_max>τ_p` | 单框 ×**1.15** | MedSAM |
| M 疑似漏检 | `0<fg_ratio≤τ_a` **或 `box is None`** | 多候选框（概率图降阈值取 top-k≤3）×{1.0,1.15} | MedSAM 各出 → 并集 |
| N 无病变 | `fg_ratio==0` 且 `prob_max<τ_n` | 弃权（空掩膜） | — |

3. **消融矩阵**（单变量，主证据）：

| 编号 | 配置 | 隔离什么 |
|---|---|---|
| B0 | 单框 s=1.0 → MedSAM | 基线 **0.6457** |
| B1 | 全局外扩 ×1.15 | 外扩增益 |
| B2 | 全局多候选（不分档） | 多候选增益 |
| **B3** | **分档**（H/M/N） | **主结果** |
| B4 | B3 + M 档多尺度 | 是否再加分 |
| B5 | B3 但 N 不弃权 | 弃权价值（正常图假阳） |

每项统一报：**端到端 Dice（96，无框记 0）+ 无框率 + 病灶 Dice + 正常图 `fg_ratio`**。

4. **成功判据**：**B3 > B0**，且 **B3 ≥ max(B1, B2)**（证明"分档"本身有价值）；正常图假阳不劣化。
5. **产出**：`results/tier_prompt.json`；图——分档贡献堆叠条 + 阈值敏感性曲线。
