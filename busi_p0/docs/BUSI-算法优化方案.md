# BUSI 分割 · 模型/算法优化方案（基于统一协议实测）

> 依据：`docs/七种模型对比.md` 的统一协议结果（同划分/同指标/同后处理）。
> 所有预期增益以**多种子标准差（监督式 ≈ 0.02）**为判定门槛：改动需 > std 才算有效。

## 一、现状与瓶颈（实测）

| 组别 | 最佳方法 | Dice(病灶) | 召回 | HD95 |
|---|---|---|---|---|
| 监督式（全自动） | TransUNet | 0.6911 | 0.723 | 111.4 |
| 提示式（单点） | BUSSAM | 0.8361 | 0.856 | 35.0 |

**关键症结**：
1. **漏检**：监督式召回 ~0.71–0.72，而 BUSSAM 0.856 → 提升监督式召回是最大空间。
2. **边界差**：监督式 HD95 111–160，BUSSAM 仅 35 → 轮廓/边界优化价值大。
3. **门控无效**：U-Net → Attention U-Net Δ=−0.0004、p=0.34 → **结构微调（注意力门控类）性价比低，不建议再投入**。
4. 提示式已很强（BUSSAM 0.836），瓶颈在**需人工/自动提示** → 全自动化是方向。

## 二、优化方案（按性价比排序）

### A. 零训练成本（直接在现有 checkpoint 上验证）
| 编号 | 方案 | 目标 | 预期 |
|---|---|---|---|
| A1 | 后处理：最大连通域 + 填洞 + 面积阈值(>0.1%) | 降 HD95/ASD、降正常图假阳性 | HD95 明显↓，Dice 平/微升 |
| A2 | 测试时增强 TTA（多尺度+翻转平均） | 稳 Dice | +0.01~0.02 |
| A3 | 前景阈值搜索（0.5→最优） | 平衡 P/R | 微升 |

### B. 低训练成本（重训，GPU 分钟级）
| 编号 | 方案 | 目标 | 预期 |
|---|---|---|---|
| B1 | **Tversky loss (α=0.3, β=0.7)** | 直接提召回 | 召回 +0.05~0.10 |
| B2 | CE + Dice + **Boundary loss** | 优化边界 | HD95↓，恶性 Dice↑ |
| B3 | 充分训练（24→100~150 ep + 早停） | 检查是否欠拟合 | +0.00~0.03 |
| B4 | 分辨率 128→256（U-Net/AttU-Net） | 小病灶细节 | +0.02~0.04 |

### C. 中成本（利用已训好的 BUSSAM，性价比最高）
| 编号 | 方案 | 目标 | 预期 |
|---|---|---|---|
| C1 | **知识蒸馏**：BUSSAM 软/硬伪标签 → 蒸馏到 U-Net/UNet++ | 轻量模型逼近大模型 | 监督式 0.69→0.75+ |
| C2 | 半自动管线：轻量 CNN 生成框 → 喂 SAM/MedSAM/BUSSAM | 免人工提示 | 自动且接近 0.83~0.91 |
| C3 | 集成：提示式+监督式按不确定度融合 | 高召回 | 互补提升 |

### D. 结构改进（成本高、收益不确定，低优先）
- D1 CNN+Transformer 混合编码器（需预训练才有效，本机无预训练权重）。
- D2 边界细化模块 / 可变形卷积 / 多尺度注意力。
- D3 BUSSAM 变体：加自动提示头、换更大 backbone（vit_l/h）。

### E. 数据层面
- E1 超声专用增强：弹性形变、乘性散斑、增益/对比度、Gamma、声影。
- E2 多病灶实例化处理（当前按“或”合并，可能混淆实例指标）。

### F. 明确不做（已被证据/资源约束反证）
- 注意力门控类结构微调（p=0.34，无显著增益）。
- TransUNet/ViT 加载 ImageNet 预训练（权重 Google Drive/Baidu，本机不可达）。
- 修改 SAM 内部结构（成本高、收益不确定，用现成提示 + 后处理即可）。

## 三、推荐执行顺序

```
1) A1~A3  零成本，先拿确定性收益（后处理/TTA/阈值）
2) B1+B2  对症"漏检 + 边界"（Tversky + Boundary），3 种子验证
3) C1     蒸馏：BUSSAM → 轻量监督式（性价比最高）
4) E1     超声专用增强
5) B4/D   分辨率与结构（可选）
```

## 四、预期收益（经验估计，需实测）

- 监督式 Dice：0.6911 → **0.72~0.76**（Tversky + Boundary + 后处理）
- 监督式 HD95：111~160 → **明显下降**（边界损失 + 后处理）
- 蒸馏后轻量模型：逼近 BUSSAM 的 0.83，且推理成本低
- 全自动管线（C2）：自动化 + 接近提示式上限
