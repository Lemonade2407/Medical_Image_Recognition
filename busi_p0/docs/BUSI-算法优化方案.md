# BUSI 分割 · 模型/算法优化方案（基于统一协议实测）

> 依据：`docs/七种模型对比.md` 的统一协议结果（同划分/同指标/同后处理）。
> 所有预期增益以**多种子标准差（监督式 ≈ 0.02）**为判定门槛：改动需 > std 才算有效。

## 一、现状与瓶颈（实测）

| 组别 | 最佳方法 | Dice(病灶) | 召回 | HD95 |
|---|---|---|---|---|
| 监督式（全自动） | TransUNet | 0.6911 | 0.723 | 111.4 |
| 提示式（单点） | BUSSAM | 0.8361 | 0.856 | 35.0 |

**关键症结**：
1. **漏检**：监督式召回 ~0.71–0.72，而 BUSSAM 0.856 → 提升监督式召回是最大空间。
2. **边界差**：监督式 HD95 111–160，BUSSAM 仅 35 → 轮廓/边界优化价值大。
3. **门控无效**：U-Net → Attention U-Net Δ=−0.0004、p=0.34 → **结构微调（注意力门控类）性价比低，不建议再投入**。
4. 提示式已很强（BUSSAM 0.836），瓶颈在**需人工/自动提示** → 全自动化是方向。

## 二、优化方案（按性价比排序）

### A. 零训练成本（直接在现有 checkpoint 上验证）
| 编号 | 方案 | 目标 | 预期 |
|---|---|---|---|
| A1 | 后处理：最大连通域 + 填洞 + 面积阈值(>0.1%) | 降 HD95/ASD、降正常图假阳性 | HD95 明显↓，Dice 平/微升 |
| A2 | 测试时增强 TTA（多尺度+翻转平均） | 稳 Dice | +0.01~0.02 |
| A3 | 前景阈值搜索（0.5→最优） | 平衡 P/R | 微升 |

### B. 低训练成本（重训，GPU 分钟级）
| 编号 | 方案 | 目标 | 预期 |
|---|---|---|---|
| B1 | **Tversky loss (α=0.3, β=0.7)** | 直接提召回 | 召回 +0.05~0.10 |
| B2 | CE + Dice + **Boundary loss** | 优化边界 | HD95↓，恶性 Dice↑ |
| B3 | 充分训练（24→100~150 ep + 早停） | 检查是否欠拟合 | +0.00~0.03 |
| B4 | 分辨率 128→256（U-Net/AttU-Net） | 小病灶细节 | +0.02~0.04 |

### C. 中成本（利用已训好的 BUSSAM，性价比最高）
| 编号 | 方案 | 目标 | 预期 |
|---|---|---|---|
| C1 | **知识蒸馏**：BUSSAM 软/硬伪标签 → 蒸馏到 U-Net/UNet++ | 轻量模型逼近大模型 | 监督式 0.69→0.75+ |
| C2 | 半自动管线：轻量 CNN 生成框 → 喂 SAM/MedSAM/BUSSAM | 免人工提示 | 自动且接近 0.83~0.91 |
| C3 | 集成：提示式+监督式按不确定度融合 | 高召回 | 互补提升 |

### D. 结构改进（成本高、收益不确定，低优先）
- D1 CNN+Transformer 混合编码器（需预训练才有效，本机无预训练权重）。
- D2 边界细化模块 / 可变形卷积 / 多尺度注意力。
- D3 BUSSAM 变体：加自动提示头、换更大 backbone（vit_l/h）。

### E. 数据层面
- E1 超声专用增强：弹性形变、乘性散斑、增益/对比度、Gamma、声影。
- E2 多病灶实例化处理（当前按“或”合并，可能混淆实例指标）。

### F. 明确不做（已被证据/资源约束反证）
- 注意力门控类结构微调（p=0.34，无显著增益）。
- TransUNet/ViT 加载 ImageNet 预训练（权重 Google Drive/Baidu，本机不可达）。
- 修改 SAM 内部结构（成本高、收益不确定，用现成提示 + 后处理即可）。

## 三、推荐执行顺序

```
1) A1~A3  零成本，先拿确定性收益（后处理/TTA/阈值）
2) B1+B2  对症"漏检 + 边界"（Tversky + Boundary），3 种子验证
3) C1     蒸馏：BUSSAM → 轻量监督式（性价比最高）
4) E1     超声专用增强
5) B4/D   分辨率与结构（可选）
```

## 四、预期收益（经验估计，需实测）

- 监督式 Dice：0.6911 → **0.72~0.76**（Tversky + Boundary + 后处理）
- 监督式 HD95：111~160 → **明显下降**（边界损失 + 后处理）
- 蒸馏后轻量模型：逼近 BUSSAM 的 0.83，且推理成本低
- 全自动管线（C2）：自动化 + 接近提示式上限

## 五、实现与运行（A1/A2/A3、B1/B2 已落地）

### 代码落点
| 编号 | 实现位置 | 说明 |
|---|---|---|
| A1 | `src/busi_common.py` → `postprocess_mask()` | 填洞 → 最大连通域 → 面积闸门(<0.1% 判空) |
| A2 | `src/eval_postproc.py` → `prob_map_original_res(tta=True)` | 尺度 {0.75,1.0,1.25} × {原图,hflip}，概率域平均 |
| A3 | `src/eval_postproc.py` → `search_threshold()` | **仅用验证集**搜阈值，目标=病灶图平均 Dice |
| B1 | `src/train_supervised.py` → `tversky_loss()` | `--loss tversky`，β=0.7 重罚假阴性（CE+Tversky） |
| B2 | `src/train_supervised.py` → `boundary_loss()` | `--loss boundary`，CE+Dice+λ·Boundary（有向距离图） |

### 运行
```bash
# B1 / B2：重训（基线 ce_dice 文件名保持不变，不会覆盖已有结果）
python train_supervised.py --model unet --size 128 --gray --epochs 24 --seed 0 \
       --loss tversky --save-ckpt
python train_supervised.py --model unet --size 128 --gray --epochs 24 --seed 0 \
       --loss boundary --lambda-bd 1.0 --save-ckpt

# A1/A2/A3：在已有权重上推理，一次性输出全部组合
python eval_postproc.py --ckpt results/ckpt/unet_s128g_e24_seed0.pt \
       --model unet --size 128 --gray --tta
```

`eval_postproc.py` 输出 `results/postproc_<tag>_seed<k>.json`，内含：
`baseline / A3 / A1 / A1+A3`（`--tta` 时再加 `A2 / A2+A1 / A2+A3 / A2+A1+A3`）各变体的
`dice_lesion / iou_lesion / precision / recall / hd95 / asd`，以及验证集搜出的阈值。

### 报告口径（重要）
- **主表不改**：A1/A2/A3 属推理侧附加项，按协议单独成表，不并入"统一后处理=无"的主结果。
- **阈值只用验证集**：A3 在 val 上搜索，测试集仅用于最终评分，避免调参泄漏。
- **单变量原则**：B1 把 Dice 换成 Tversky；B2 在 CE+Dice 上加一项。每次只动一个变量，便于归因。
- **判定门槛不变**：增益需 > 种子标准差(≈0.02) 且 Wilcoxon p<0.05 才算有效，建议每个 B 变体跑 3 种子。

## 六、优化执行结果（实测，3 种子；详见 `docs/七种模型对比.md` 第七节）

**监督式（B=重训，A=推理侧）**

| 模型 | 损失(B) | B: Dice | A 最优变体 | A 后 Dice | Δ(A) | HD95(base→best) |
|---|---|---|---|---|---|---|
| U-Net | ce_dice | 0.6137±0.0331 | A2+A1+A3 | 0.6293±0.0072 | +0.016 | 155→144 |
| U-Net | **tversky** | **0.6492±0.0126** | A3 | 0.6501±0.0134 | +0.000 | 125→127 |
| U-Net | boundary | 0.5628±0.0490 | A2+A1+A3 | 0.6002±0.0420 | +0.037 | 181→147 |
| AttU-Net | ce_dice | 0.6292±0.0028 | A2+A1+A3 | **0.6508±0.0086** | +0.022 | 154→138 |
| AttU-Net | **tversky** | 0.6444±0.0101 | A2_tta | 0.6495±0.0074 | +0.005 | 131→133 |
| AttU-Net | boundary | 0.5512±0.0126 | A3 | 0.5628±0.0012 | +0.012 | 193→161 |
| UNet++ | ce_dice | 0.6265±0.0083 | A2+A1+A3 | 0.6417±0.0063 | +0.015 | 141→**117** |
| UNet++ | tversky | 0.6039±0.0220 | A2+A1+A3 | 0.6163±0.0317 | +0.012 | 151→145 |
| TransUNet | ce_dice | 0.6817±0.0231 | A2+A1+A3 | 0.6927±0.0023 | +0.011 | 119→113 |
| TransUNet | **tversky** | 0.6958±0.0035 | A3 | **0.6992±0.0054** | +0.003 | 106→**105** |

> UNet++/TransUNet 的 boundary 已跳过（前两组已证其有害、且训练慢 2.5×）。TransUNet 的 TTA 仅用**翻转**（多尺度会破坏其固定位置编码）。

**提示式（仅 A，无 B）**：SAM baseline 0.6034 → A2+A1+A3 **0.5809（变差）**；MedSAM 0.1096 → **0.0106（崩溃）**；BUSSAM 0.8364 → A2_tta **0.8411（微升 +0.005）**。

> 一句话：**B**——Tversky 对**小模型**有效（U-Net +0.036、AttU-Net +0.015），对 **UNet++ 反而有害**（−0.023），对 TransUNet 略正（+0.014）；**Boundary 一致有害**。
> **A（A2+A1+A3）**——对**全部 4 个监督式**稳定有效（**+0.011~0.037**），且 **HD95 普遍下降**（最多 193→161、181→147、141→117）。**对提示式无效甚至有害**。
> **全局最优**：**TransUNet + tversky + A3 = 0.6992**（HD95 105，监督式最佳）。

## 七、论文创新点（基于上述实测，实际可行）

> 每个点都**用本仓库已有设施即可完成**（冻结划分 `splits/busi_seed0.json`、统一指标 `busi_common.py`、已训好的 7 个模型、A/B 脚本）。

**C1. 推理侧增强的"跨范式适用边界"（已有数据支撑，最有把握）**
- 实证：同一套推理侧增强（后处理/TTA/验证集阈值）在**监督式**上稳定增益（+0.015~0.022、HD95 降 10~35），在**提示式大模型**上**无效甚至有害**（SAM −0.02、MedSAM 崩溃）。
- 机理：监督式的密集预测存在孤立假阳/孔洞，后处理可修；提示式输出已是单一干净前景，**面积门限会误删小病灶**。
- 创新点：提出**"零成本推理增强 + 适用性判据"**（依预测稀疏度/空掩膜比例/形态复杂度决定是否启用），并给出跨范式对照证据。这是一个"即插即用"的通用模块 + 准则，容易写成方法+实验的完整故事。

**C2. 验证集阈值选择 + 面积闸门的可复现协议**
- 在**验证集**上搜前景阈值（杜绝测试集调参），对 boundary-loss 模型增益最大（+0.037）。
- 可作为一个规范做法写进论文的"实验协议"，成本为零、收益稳定。

**C3. 损失函数的"有效边界"实证（Tversky 有效 / Boundary 单独无效）**
- Tversky(α=0.3, β=0.7) 显著提分（U-Net +0.036）；**Boundary 单独使用反而变差**（−0.05~−0.08），需与 Dice 联合或调 λ。
- 创新点：在小数据超声分割上给出**损失函数有效/无效的对照证据与适用条件**，比"只报告涨点"更有信息量。

**C4. 统一协议 + 统计严谨的跨方法基准（方法学贡献）**
- 冻结划分 + 同口径指标 + 多种子 mean±std + 配对 Wilcoxon；**据此否定了注意力门控**（p=0.34）。
- 创新点：为"提示式 vs 监督式"提供**公平、可复现、可判别**的评测框架——同类工作中普遍缺失。

**C5. 提示式教师 → 轻量监督式学生的蒸馏管线（推荐下一步，成本可控）**
- 用 **BUSSAM(0.836)** 生成伪标签 → 蒸馏到 U-Net/UNet++：把大模型能力"固化"成全自动轻量模型。
- 已有：BUSSAM 权重、训练/评估脚本、冻结划分。只需加一个蒸馏损失项。

**C6. 免人工提示的自动分割管线**
- 轻量 CNN/检测器自动出框 → 驱动 MedSAM（框提示 **0.912**）/BUSSAM（**0.836**）。
- 创新点：消除提示依赖，实现**全自动高精度**；可用"框质量 vs 最终 Dice"做消融。

**C7.（可选）速度-精度前沿**：把 A 组做成"可调档位"（baseline / +TTA / +TTA+后处理 ≈ +27% 推理时间换 +0.02 Dice），给出部署侧的 Pareto 曲线。

### 建议的论文主线（把 C1–C4 串起来）
> **问题**：BUSI 上方法众多但口径不一、结论不可比。**方法**：统一评估协议 + 严格统计；并系统评测"重训侧损失（Tversky/Boundary）"与"推理侧增强（后处理/TTA/阈值）"。**发现**：Tversky 有效、Boundary 单独无效、推理增强对监督式有效而对提示式有害（给出判据）。**延伸**：BUSSAM 蒸馏出全自动轻量模型（C5/C6）。

## 八、C5 / C6 实施计划（可落地）

> 前置资产：BUSSAM 最优权重（0.836）、4 个监督式 checkpoint、`splits/busi_seed0.json`、`busi_common.py` 指标、A/B 脚本框架。

### 8.1 C5　提示式教师 → 轻量监督式学生的蒸馏

**数据流**
```
图像 → BUSSAM(提示) → 软概率伪标签 ─┐
                                    ├─► 学生训练: L = L_sup(GT) + λ·L_KD
图像 + GT 掩膜 ─────────────────────┘   → 全自动学生(U-Net/UNet++)
```

**实施步骤**
1. **生成伪标签** `src/gen_pseudo.py --teacher bussam --split train,val --prompt {gtbox,autobox,gtpoint}`
   → `results/pseudo/bussam/<split>/<name>.npy`（原图分辨率 **软概率**，比硬标签信息更多）。
2. **蒸馏训练**：给 `train_supervised.py` 加参数
   `--pseudo-dir … --lambda-kd 0.5 --kd-warmup 5 --kd-gate 0.9`
   - 损失：`L = CE+Dice(GT) + λ·KD`；KD = 对**教师置信像素**(p>0.9 或 p<0.1) 的 KL/BCE（避免学到模糊边界噪声）。
   - 教师概率 resize 到学生分辨率（128/256）；前 `warmup` 轮只用 GT。
3. **评估**：统一指标 + 冻结测试集 + 3 种子（学生推理**不需要教师/提示** → 全自动）。

**消融矩阵**：学生 {U-Net, UNet++} × 教师提示 {GT 框(上界), 自动框(C6), GT 点} × λ {0, 0.25, 0.5, 1.0} × 门控 {无, 0.9} × warmup {0, 5}。

**成本**：伪标签 ~3 min；每次训练 U-Net 25 s / UNet++ 4 min；主实验（2 学生 × 3 种子）≈ 15 min。
**预期**：U-Net 0.636 → **0.66~0.70**；UNet++ 0.642 → **0.68~0.71**。

**效度与风险**：BUSSAM 已在**训练集**上微调 → 对训练图像可能"记忆"，伪标签偏优、收益被夸大。
缓解：① 只看**冻结测试集**成绩（学生推理不含教师）；② 增设"教师未见过图像"的半监督对照；③ 报告与"纯 GT 训练"的**差值**而非绝对值。若收益≈0，本身也是可发表的负结果。

### 8.2 C6　免人工提示的自动分割管线

**数据流**
```
图像 → 阶段1 粗定位（自动出框/点） → 阶段2 提示式精修（MedSAM 框 / BUSSAM·SAM 点） → 掩膜
```

**阶段1 的三种实现（对比）**
- **P-a 复用已训分割模型（最省）**：U-Net/UNet++ 预测掩膜 → 最大连通域外接框（可外扩 k%）。**零额外训练**。
- **P-b 轻量检测器**：从 GT 掩膜导出框作为标注 → 训一个小 CNN/YOLO 出框（~15 min）。
- **P-c 自提示迭代**：用监督式掩膜质心作点 → SAM/BUSSAM → 用输出再迭代 1–2 轮。

**阶段2**：框 → MedSAM（框最优 **0.912**）；点 → BUSSAM（**0.836**）/SAM。

**论文核心消融**：**提示质量 vs 最终 Dice**
- 对 GT 框做抖动（缩放 ±5/10/20%、平移、掺入无关区域），画 `最终 Dice ~ IoU(框,GT框)` 曲线，3 个提示模型各一条 → 定量给出"提示式模型对提示误差的鲁棒性"。
- 提示来源：oracle 框 / auto 框(U-Net) / auto 框(UNet++) / 抖动框。

**成本**：auto 管线评估 ~5 min；抖动消融（5 档 × 96 图 × 3 模型）≈ 20 min（可并行）。
**预期**：auto 框（来自 UNet++）较紧 → MedSAM 最终 **≈0.85~0.90**（对比 oracle 0.912、监督式最佳 0.70）→ **全自动且高精度**。

**风险**：正常图可能被阶段1 出假框 → 需"无前景则跳过"判据（用前景占比阈值）；框过大时 MedSAM 易过分割。

### 8.3 C5+C6 联合（真正端到端）
```
UNet++(auto) → auto-box → MedSAM → 伪标签 → 蒸馏 U-Net  →  全自动/轻量/高精度学生
```
这条线把 C1–C6 串成一个完整故事。

| 步骤 | 内容 | 耗时 | 产出 |
|---|---|---|---|
| 1 | C6-a：监督式出框 + MedSAM/BUSSAM，含框鲁棒性曲线 | ~30 min | 全自动管线 + 消融 |
