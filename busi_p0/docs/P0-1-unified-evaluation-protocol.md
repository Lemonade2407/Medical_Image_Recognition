# P0-1　统一评估协议（BUSI 七方法）

> 配套：`splits/busi_seed0.json`、`src/busi_common.py`（指标唯一实现）、`results/`
> 本协议是后续所有 P0-2 / P1 / P2 实验的地基：**任何方法不得单独偏离**。

## 1. 为什么需要它

原始三份报告里，两组方法的**划分、分辨率、IoU 口径、Dice 算法都不一致**，导致跨方法绝对数值不可比
（如 `test_metrics.json` 的病灶 Dice 是"含 20 张正常图、正常图记 0"的平均，而分层表里是"仅病灶图"的平均）。
本协议把所有方法钉在同一份划分与同一套指标定义上。

## 2. 数据集与划分（唯一划分文件）

- 数据：BUSI，780 张超声图（benign 437 / malignant 210 / normal 133），像素级 mask；
  多病灶病例（17 例含 `_mask_1.png`）按**或**合并为单张前景。
- 划分：`splits/busi_seed0.json`，按类别分层，比例 70/15/15，种子 42，
  使用**最大余数法 + val 优先于 test 的平局规则**分配，复现原报告的 546/118/116。

| 类别 | 训练 | 验证 | 测试 | 合计 |
|---|---|---|---|---|
| benign | 306 | 66 | 65 | 437 |
| malignant | 147 | 32 | 31 | 210 |
| normal | 93 | 20 | 20 | 133 |
| **合计** | **546** | **118** | **116** | **780** |

- 测试集 **116 张 = benign 65 + malignant 31 + normal 20**（病灶图 96 张，正常图 20 张）。
- **所有方法（含提示式）都在这一份测试集上评估**；训练/验证也只用这一份训练/验证列表。
- 划分文件一旦生成即冻结，不得在训练时现场随机重划。

## 3. 指标定义（写死，唯一定义见 `src/busi_common.py`）

所有指标在**原始分辨率**上计算：模型输出（128/256/1024）按最近邻 resize 回原图尺寸，再与同尺寸 GT 比较。

| 指标 | 口径 |
|---|---|
| Dice(病灶) | **仅在病灶图（benign+malignant，96 张）上**逐图 Dice 的平均 |
| Dice(全体) | 全部 116 张逐图 Dice 的平均（正常图 Dice 记 0）——仅作参考 |
| 病灶 IoU | 逐图病灶类 IoU（`inter/union`）的平均，仅病灶图 |
| mIoU | **像素直方图法**：全局混淆矩阵算背景/前景两类 IoU 取平均（含背景） |
| 精确率 / 召回率 / 特异度 / 准确率 | **全局像素混淆矩阵**（116 张像素累加）计算 |
| HD95 | 边界 95 分位双向 Hausdorff 距离，单位=原图像素；仅病灶图平均 |
| ASD | 平均表面距离（双向），单位=原图像素；仅病灶图平均 |
| 正常图假阳性 | 20 张正常图上"预测前景占比"的均值（越小越好） |
| 分层 | 另报 benign / malignant 分组的病灶 Dice |

空掩膜约定：GT 与预测均为空 → Dice=1、HD95=ASD=0；仅一方为空 → Dice=0、HD95=ASD=图像对角线长度。

## 4. 后处理策略

**统一不做后处理**（不连通域过滤、不填洞、不面积阈值）。所有方法的主表结果均为原始 argmax 输出；
P1-3 的连通域/填洞/面积过滤将作为**统一附加**单独报告，不在主表中混用。

## 5. 各方法的输入与预处理（记录在协议表，测试集一致）

| 方法 | 输入尺寸 | 通道 | 归一化 | 提示 |
|---|---|---|---|---|
| U-Net | 128 | 灰度 | 逐图零均值单位方差 | 无（全自动） |
| Attention U-Net | 128 | 灰度 | 逐图零均值单位方差 | 无 |
| UNet++ | 256 | RGB | 逐通道零均值单位方差 | 无 |
| TransUNet | 256 | RGB | 逐通道零均值单位方差 | 无 |
| SAM ViT-B | 1024（内部） | RGB | SAM 官方预处理 | 1 个 GT 前景中心正点 |
| MedSAM ViT-B | 1024（内部） | RGB | MedSAM 官方预处理 | 1 个 GT 前景中心正点 |
| BUSSAM ViT-B | 1024（内部） | RGB | BUSSAM 官方预处理 | 1 个 GT 前景中心正点 |

> 说明：输入尺寸属于**模型超参**（各方法保留自身原生设置并在此登记）；协议统一的是
> **数据划分 + 指标定义 + 评估分辨率 + 后处理**。这是"评估协议统一"，不是"结构统一"。

## 6. 跨方法一致性核对（验收）

- 每个方法的结果 JSON 都携带 `per_image` 列表，其 `name` 集合必须**恰好等于** `splits/busi_seed0.json`
  中对应的测试文件名集合（提示式方法为其病灶子集 96 张）。
- `src/verify_consistency.py` 对 `results/*.json` 逐个核对：测试集逐文件一致、指标口径字段齐全。
  只有全部通过，才允许把该方法写入对比表。

- 本协议文档
- `src/busi_common.py`（指标唯一实现，所有方法 import 同一份）
- `src/verify_consistency.py`（一致性核对）
