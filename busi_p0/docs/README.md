## 归档约定

- 目录名 `P<编号>_v<版本>_<YYYY-MM-DD>`，内含 `code/`、`preds/`、`figs/`、`tables/`、`results/`。
- 说明文档写入 `docs/`，归档内不重复存放文档。
- `preds/*.npz`：每个变体一份，键为图像名（`/` → `__`），值为原始分辨率的布尔掩膜。
- `sha256sums.txt`：`sha256sum -c sha256sums.txt` 必须全 OK。
- 归档由脚本生成（`src/archive_p3.py`），不手工拼装。
