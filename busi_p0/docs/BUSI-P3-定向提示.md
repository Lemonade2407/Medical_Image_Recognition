## 一、一句话结论

粗模型“完全不出框”（全盲）是端到端最大的可回收损失：给这些图补**中心框兜底提示**，端到端 Dice **0.6542 → 0.6768**（**+0.0226**，p=0.002，12 好 / 0 差，3 个种子 Δ 分别 +0.0265 / +0.0224 / +0.0191），无框率 **9.0% → 0.7%**；代价是正常图假阳 **0.0036 → 0.0746（交集）/ 0.1888（多数投票）**，因为正常图与漏检病灶在二分类分割输出上不可分（判据精度上限 0.41）。

## 六、已知限制

1. 只跑了 UNet++（4 个监督式之一）；换成更强的粗模型时全盲图会减少，增益预计随之收窄（未验证）。
2. 正常图假阳代价**未根本解决**（特异度 0.996→0.93/0.81），判据精度上限 0.41；P4 用图像级 presence 门控把它压到 fg **0.0378**（−80%），但仍高于 B0 的 0.0036，且合法阈值下前置判据未过（见 `docs/BUSI-P4-门控兜底.md`）。
3. 粗模型与精修器都固定，**不含任何重训**；这是推理侧零成本方案的属性，也是其上限。
4. 掩膜为原始分辨率布尔图；npz 键把 `/` 替换为 `__`。

## 七、种子稳健性

- 基线 B0：**0.6542±0.0359**；全盲兜底（多数投票）：**0.6768**（**+0.0226**）
- 无框率：**9.0% → 0.7%**
- **3/3 种子 Δ 为正**（+0.027 / +0.022 / +0.019），均值 +0.0226 → 收益来自机制，而非偶发。
