## 约定

- 目录名 `P<编号>_v<版本>_<YYYY-MM-DD>`。
- `MANIFEST.md` 必须写明：结论、环境、复现命令、目录清单、关键数字、**已知限制**。
- `preds/*.npz`：每个变体一份，键为图像名（`/` → `__`），值为原始分辨率的布尔掩膜。
- `sha256sums.txt`：`sha256sum -c sha256sums.txt` 必须全 OK。
- 归档由脚本生成（如 `src/archive_p3.py`），不手工拼装，确保可重跑。
